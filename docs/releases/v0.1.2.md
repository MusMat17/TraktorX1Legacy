# TraktorX1Legacy v0.1.2 — Stable

**Traktor Kontrol X1 Mk1 снова работает с Traktor Pro 4 на Intel Mac с macOS Monterey.**

TraktorX1Legacy — независимое приложение-мост, которое подключает оригинальный **Native Instruments Traktor Kontrol X1 Mk1** к современному Traktor через **USB → libusb → CoreMIDI**. Оно работает в пользовательском пространстве, без установки устаревшего NI USB-kext.

> **Статус:** стабильный релиз по результатам проверки на реальном X1 Mk1. Это независимый проект сообщества, не официальный продукт Native Instruments.

## Совместимость

| Компонент | Проверенная конфигурация |
| --- | --- |
| Контроллер | Traktor Kontrol X1 **Mk1** (USB VID:PID `17cc:2305`) |
| Компьютер | MacBookPro9,2 — Intel x86_64 (MacBook Pro 13″ Mid 2012) |
| macOS | **Monterey 12.7.x** через OpenCore Legacy Patcher |
| DJ-приложение | **Traktor Pro 4** |
| Архитектура сборки | Intel x86_64 |
| Минимальная версия macOS в Mach-O | 12.0 |

Сборка предназначена для Intel Mac с macOS 12 и новее, но практическое тестирование подтверждено прежде всего для указанной конфигурации. Совместимость со всеми версиями macOS/Traktor и Apple Silicon **не заявляется**.

## Возможности

- Работа кнопок, FX-регуляторов, энкодеров Browse/Loop и транспортных органов управления.
- Слои **SHIFT** и **HOTCUE**.
- Обратная связь **LED** от Traktor, включая индикацию эффектов.
- Обнаружение контроллера при запуске, подключении и повторном подключении USB.
- Виртуальные входной и выходной порты **CoreMIDI**.
- Работа со встроенным профилем **TraktorKontrol X1** без отдельного TSI в проверенной конфигурации.
- Значок 🎛️ в строке меню macOS со статусом подключения и командой **Quit TraktorX1Legacy**.
- Команда диагностики `--diagnose`; опциональный автозапуск через LaunchAgent.

## Что нового именно в v0.1.2

1. **Исправлена иконка:** добавлено выбранное детализированное оформление **X1 / LP (Legacy Patch)**, а не упрощённая SVG-перерисовка. Иконка встроена в `.app` в формате `.icns`, с отдельным именем ресурса для предотвращения путаницы со старым кешем Finder.
2. **Нормальное завершение:** в выпадающем меню верхней панели появилась команда **Quit TraktorX1Legacy**. Она остаётся доступной при подключении и отключении контроллера.
3. **Проверка пакета:** улучшены CI-проверки ZIP, подписи, версии приложения и содержимого bundle.
4. **USB/MIDI-логика без изменений:** функциональность, уже проверенная на X1 Mk1, сохранена.

Ранее, в v0.1.0, шесть FX-кнопок 1/2/3 были переведены на отправку нажатия **127** и отпускания **0**. Это физические MIDI-события, а не переключение состояния эффекта внутри моста.

## Установка / обновление

1. Скачайте **`TraktorX1Legacy_x86_64-apple-darwin_macos12.0+.zip`** из блока **Assets** ниже.
2. Закройте работающую старую версию через пункт **Quit**, либо через Activity Monitor, если используется версия до v0.1.2.
3. Распакуйте ZIP, переместите **TraktorX1Legacy.app** в `/Applications` и согласитесь на замену.
4. Подключите X1 Mk1 по USB и запустите приложение.
5. В Traktor Pro 4 проверьте `Preferences → Controller Manager`:
   - **Device:** `TraktorKontrol X1`
   - **In-Port:** `KontrolX1`
   - **Out-Port:** `KontrolX1`

Для обычной работы в проверенной конфигурации не требуется импорт дополнительного `.tsi`.

**Первый запуск и безопасность.** Приложение подписано тестовой **ad-hoc** подписью, без Apple notarization. macOS может запретить запуск после скачивания, особенно при передаче файла через Telegram. Сначала попробуйте **Finder → правый клик по приложению → Open** или разрешение в **System Preferences → Security & Privacy**. Только после проверки происхождения архива можно снять карантин с *этого конкретного приложения*:

```sh
xattr -dr com.apple.quarantine /Applications/TraktorX1Legacy.app
open /Applications/TraktorX1Legacy.app
```

Не требуется отключать SIP, Gatekeeper для всей системы или устанавливать старый `NIUSBController.kext`.

## Известные ограничения

- Для FX-кнопок **Traktor Interaction Mode = Toggle** во встроенном профиле у одного из тестировщиков остаётся конфликт: `Hold` работает, а `Toggle` может не срабатывать. Это проблема взаимодействия с назначениями в Traktor, **не объявленная исправленной** в v0.1.2. См. [Issue #7](https://github.com/MusMat17/TraktorX1Legacy/issues/7).
- Порт представлен как виртуальный **MIDI**, а не полностью эмулированное устройство NI NHL.
- Приложение работает в строке меню (`LSUIElement`): значок в Finder/Launchpad есть, постоянной иконки в Dock во время работы нет.
- Совместимость на других Mac и macOS требует отдельной проверки.

# English summary

**TraktorX1Legacy v0.1.2** brings the original **Traktor Kontrol X1 Mk1** back to **Traktor Pro 4** on a tested **Intel MacBookPro9,2 running macOS Monterey 12.7.x with OCLP**, using a userspace **USB → libusb → CoreMIDI** bridge. No obsolete Native Instruments kernel extension or system-wide security downgrade is required.

**Key functionality:** buttons, knobs, Browse/Loop encoders, transport, SHIFT/HOTCUE layers, Traktor-controlled LEDs, USB hot-plug/reconnect, virtual CoreMIDI ports, and the built-in `TraktorKontrol X1` profile. In the tested configuration, no additional TSI import was required.

**New in v0.1.2:** the detailed X1/LP app icon has been restored, a persistent **Quit TraktorX1Legacy** command has been added to the macOS menu-bar menu, and packaging/smoke tests have been improved. Previously validated USB/MIDI behavior is unchanged.

**Installation:** extract the Intel/macOS 12+ ZIP, copy the app to `/Applications`, connect the controller, launch the bridge, then select `TraktorKontrol X1` with `KontrolX1` as both In-Port and Out-Port in Traktor. The app is ad-hoc signed rather than notarized; Gatekeeper approval may be necessary on first launch.

**Known limitation:** some custom `Toggle` interactions for FX 1/2/3 under Traktor's built-in map are still under investigation ([Issue #7](https://github.com/MusMat17/TraktorX1Legacy/issues/7)). `Hold` works. This is a virtual MIDI bridge, not complete NI NHL emulation. Other Apple hardware and macOS versions remain unverified.
